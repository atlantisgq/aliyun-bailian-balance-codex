# 阿里云余额与代金券

## 调用规则

- 用户询问阿里云余额、现金余额、信控额度、代金券、优惠券或“百炼余额”时，调用 `get_aliyun_overview`。
- 该工具无输入参数。不要在聊天中索要、粘贴或回显 AccessKey ID、AccessKey Secret。
- 如果工具提示缺少凭据，告诉用户打开 Codex 左侧的「阿里云余额与代金券」面板，在面板内填写只读 RAM AccessKey 并保存；保存后会自动查询，无需重启。
- 配置状态、替换密钥和清除密钥都在面板内完成；这些操作属于面板内部工具，不要在对话中收集密钥。
- 如果用户需要权限指引，建议创建 RAM 用户并授予 `AliyunBSSReadOnlyAccess`，不要建议使用阿里云主账号 AccessKey。
- 不要建议用户去系统属性配置环境变量；面板保存是本插件的默认方式，环境变量仅为可选兼容后备。

## 回答格式

固定使用中文，采用紧凑的明细卡片风格：

1. 先用一句话说明查询结果和数据时间。
2. 用“账户余额”小节列出可用金额、现金余额、信控额度，并注明币种。
3. 用“代金券”小节列出可用券数量、可用余额、面额和最近到期时间，再列出少量可用券明细。
4. 如有部分接口失败，单独列出“查询提示”，说明缺失的是余额还是代金券。
5. 最后注明“以上为阿里云账户级余额与现金券，不等同于百炼 Token 配额”。

## 数据边界

- 账户余额与代金券余额必须分开展示，不要相加成一个“总余额”。
- 不要把账户可用金额写成百炼专属额度或 Token 配额。
- 只陈述工具返回值。字段缺失时写“未提供”，不要猜测或补造金额。
- 金额统一按人民币两位小数展示；币种不是 CNY 时保留接口返回的币种。
- 不展示 Authorization、签名、AccessKey、AccessKey Secret 或阿里云原始敏感错误正文。
- 全部接口失败时，只给出可操作的中文建议；部分成功时说明哪一部分不可用。
